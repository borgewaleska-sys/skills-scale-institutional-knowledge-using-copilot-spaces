# OctoAcme Project Management Docs

## Overview

OctoAcme follows a customer-first, iterative delivery approach with clear ownership and data-informed decision-making. All projects follow our defined lifecycle: **Initiation → Planning → Execution → Release → Retrospective**.

Our project management processes are designed to ensure transparency, accountability, and continuous improvement across all initiatives. This documentation serves as the central hub for all institutional knowledge related to OctoAcme's project management approach.

## Key Principles

- **Customer-First Mindset**: All decisions prioritize customer value and outcomes
- **Iterative Delivery**: We deliver in increments and gather feedback continuously
- **Clear Ownership**: Every project has clearly defined roles and decision authorities
- **Data-Informed Decisions**: We use metrics and data to guide project decisions
- **Continuous Improvement**: We learn from every project through structured retrospectives

For more details on these principles and how they guide our work, see the individual process documents linked above.
